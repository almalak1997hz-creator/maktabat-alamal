مكتبة الأمل - نظام الويب

ضع هذا المجلد في نفس مجلد قاعدة البيانات maktabat_alamal.db الحالية حتى يحافظ النظام على بياناتك.

داخل Terminal في VS Code:
python -m pip install -r requirements.txt
python app.py

ثم افتح:
http://127.0.0.1:5000

الدخول الأول:
admin
1234
ثم غيّر كلمة المرور من الإعدادات.

للدخول من المنزل:
1) ثبّت cloudflared على كمبيوتر المحل.
2) شغّل البرنامج python app.py واتركه يعمل.
3) في Terminal ثانٍ شغّل:
cloudflared tunnel --url http://127.0.0.1:5000
4) سيظهر رابط https. افتحه من المنزل وسجّل الدخول.

يجب أن يبقى كمبيوتر المحل والبرنامج والاتصال بالإنترنت يعملًا للوصول عن بعد.
